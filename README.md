# Ani - Clips: Liquid-Glass Clip Library

## Test on your PC
1. Unzip the folder.
2. Double-click `index.html` to open it in your browser.

## Edit Content
- Open `clips.js` in VS Code. That is the only file you need to edit.
- `ANIME_META` controls anime poster thumbnails and Most Popular ranking.
- In `CLIPS`, set `sub: "Flow Frames"` or `sub: "Vocals"` and `series: "Anime Name"` to group characters inside any anime.
- Add `recent: true` on any character to feature them in **Recent Uploads**.
